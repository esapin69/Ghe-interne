SITE NOUVEL ARRIVANT — VERSION AGENT

1. Créez le nouveau projet Apps Script avec le code fourni séparément.
2. Exécutez une fois initialiserProjetAgent.
3. Déployez en application Web et récupérez le lien /exec.
4. Ouvrez assets/app.js et remplacez COLLER_ICI_LE_NOUVEAU_LIEN_APPS_SCRIPT_EXEC par ce lien.
5. Envoyez tout le contenu du dossier dans le dépôt GitHub, sans modifier les noms.

Le site écrit uniquement dans le fichier « Formulaire rempli par le nouvel agent ». Aucune correction orthographique n’est appliquée aux réponses de l’agent.
